# GitBloom

GitBloom creates an organized Git commit timeline from a project folder or selected files.

## How to use

1. Download GitBloom for your operating system from the [latest GitHub Release](https://github.com/DEVIDAS-CHINNARATHOD/GitBloom/releases/latest).
2. Open the downloaded application.
3. Enter your remote Git repository URL.
4. Select a project folder or select individual files.
5. Enter the start date using `DD-MM-YYYY`.
6. Check or edit the suggested number of commits.
7. Move the date slider to adjust the end date.
8. Click **Generate commit plan**.
9. Review the plan and click **Create commits**.
10. Confirm whether you want to push the commits.

## Run from source

Requirements: Python 3.10+, Git, and Tkinter.

```bash
python -m gitbloom
```
